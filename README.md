## ✨ Возможности

- **Вкладка «Задачи»** — все заметки в одном списке.
- **Приоритет задач** — эмодзи в конце названия:
  `🔴` высокий · `🟡` средний · `🟢` низкий (на сервер средний уходит без смайлика).
- **Отметка «Выполнено»** — галочка прямо в списке задач и в календаре.
- **Клик по паре** в расписании → автоматически создаётся заметка по этому предмету.
- Автоподстановка даты **ближайшей такой же пары** (одно название + тот же
  преподаватель = та же пара, даже если кабинет другой).
- Кнопки **«На день клика»** и **«Следующую пару»** при создании заметки из пары.
- **Фильтры задач**: по дате (Все/Сегодня/Эта неделя) и по приоритету.
- **Календарь** с кликабельными парами и заметками.

## 📥 Как скачать на своё устройство

### 💻 Windows (EXE)
1. Скачай файл **`Расписание ВГУ.exe`** (из раздела *Releases* на этой странице).
2. Запусти его — установка не нужна, это портативная версия.
3. Войди через Telegram-бота, как в оригинальном приложении.

### 🤖 Android (APK)
1. Скачай файл **`Расписание ВГУ.apk`** (из раздела *Releases*).
2. Открой файл и разреши установку «из неизвестных источников», если попросит.
3. Войди через Telegram-бота.

> APK не подписан — Android может предупредить о неизвестном источнике. Это
> нормально для персональной сборки: просто разреши установку.

### 🍎 iPhone (PWA)
Нативный iOS-файл с Windows не собирается, поэтому на iPhone используется
**веб-версия как приложение**:
1. Открой в **Safari** адрес: `https://<твой-аккаунт>.github.io/vsu-schedule-fork/`
2. Нажми кнопку **«Поделиться»** (квадрат со стрелкой) внизу экрана.
3. Выбери **«На экран "Домой"»** → «Добавить».
4. Открой приложение через иконку — оно запустится полноэкранно и будет
   работать офлайн (после первого открытия при наличии сети).

## 🛠 Для разработчиков (сборка из исходников)

```
app/        веб-фронтенд (index.html, app2.js, style2.css, manifest, icons, sw.js)
desktop/    Electron-обёртка для Windows (.exe)
mobile/     Capacitor-проект для Android (.apk)
```

**Web локально:** `cd app && python -m http.server 8080` → открой `http://localhost:8080`.

**EXE:** `cd desktop && npm install && $env:CSC_IDENTITY_AUTO_DISCOVERY='false' && npm run dist`

**APK:** `cd mobile && npm install && npx cap sync android && cd android && .\gradlew.bat assembleDebug`

### Страница веб-версии (GitHub Pages)

Публикация автоматическая через GitHub Actions — содержимое папки `app/`
выкладывается на https://<твой-аккаунт>.github.io/vsu-schedule-fork/.
